# Experimental Trading Bots

A collection of experimental quantitative finance and algorithmic trading projects built using Python, machine learning, market microstructure concepts, and financial data analysis.

These projects are designed to help developers, students, and quantitative enthusiasts explore how modern trading systems can be researched, modeled, visualized, and backtested.

## Projects Included

### 1. Liquidity Vacuum Trading Bot

Detect liquidity gaps and market sweeps to study price reactions around low-liquidity zones.

Topics:

* Order Book Analysis
* Liquidity Sweeps
* Market Microstructure
* Trading Simulation

---

### 2. Market Regime Rotation Bot

Use machine learning to identify bull, bear, and sideways market conditions.

Topics:

* Market Regimes
* K-Means Clustering
* Feature Engineering
* Quantitative Research

---

### 3. Order Flow Pressure Bot

Analyze buy/sell pressure to explore short-term market behavior.

Topics:

* Order Flow Analysis
* Bid/Ask Imbalance
* Market Pressure
* Quantitative Signals

---

### 4. Volatility Expansion Breakout Bot

Track volatility contractions and study breakout opportunities.

Topics:

* Volatility Analysis
* ATR
* Bollinger Bands
* Breakout Detection

---

### 5. Cross-Asset Lead-Lag Bot

Discover whether one asset consistently moves before another using lag analysis.

Topics:

* Correlation Analysis
* Cross-Correlation
* Lead-Lag Relationships
* Multi-Asset Research

## How to Fork

1. Open this repository on GitHub.
2. Click the Fork button.
3. Clone your fork:

git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git

4. Navigate into the project folder.
5. Install dependencies:

pip install -r requirements.txt

6. Run the desired project.
